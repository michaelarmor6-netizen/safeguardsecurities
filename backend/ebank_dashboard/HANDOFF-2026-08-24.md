## Addendum (later on 2026-08-24): client funding flow — auto-send funding details

Funding is now a two-step flow (was: approve = instant wallet credit):

1. Client submits a request (Wallet page, unchanged).
2. Admin **Approve & send details** → status `approved` + `awaitingPayment: true`.
   The client immediately sees a payment-instructions card on their Wallet page
   (bank wire + crypto + per-request reference code `SG-XXXXXXXX`, derived from the
   doc id), and a Firestore trigger emails them the same details.
3. Money arrives → admin **Confirm receipt & credit** → status `funded`, wallet credited.

Legacy rows approved before this change were credited at approval; they have no
`awaitingPayment` flag and never show the Confirm button (double-credit guard, also
enforced in `confirmFundingReceived`).
